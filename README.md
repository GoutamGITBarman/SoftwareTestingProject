## 📋 Project Overview

The goal of this project is to define, document, and execute a set of manual tests to validate the core functionalities and non-functional requirements of the application.  
This repository serves as a resource for:

- QA Engineers
- Developers
- Project Managers
- Stakeholders
  
## 📋 Test Plan

📄 **Location:** `/Test_Plan/TestPlan_Document.pdf`
The **Test Plan** outlines the overall strategy and scope for testing. It includes:

- Project overview and objectives  
- Testing scope and approach  
- Test environment setup  
- Entry and exit criteria  
- Risk management  
- Roles and responsibilities  
- Deliverables and timelines

## 🧪 Test Cases

All test cases are designed to ensure coverage of functional and non-functional requirements. Each test case includes:

📂 **Location:** `/Test_Cases/`

Test Case Categories:
- **Functional Test Cases**  
- **Regression Test Cases**  
- **UI Test Cases**  
- **Smoke Test Cases**
- 
Each test case includes:
- Test Case ID  
- Description and objective  
- Preconditions  
- Step-by-step actions  
- Expected result  
- Actual result (during execution)  
- Status (Pass/Fail)

Test cases are stored in spreadsheet format for clarity and easy tracking.

## 🐞 Defect Reports (Optional)

If defects are found during testing, they are logged in the **Defect Reports** section with:

- Defect ID  
- Summary  
- Steps to reproduce  
- Severity and priority  
- Status and resolution
